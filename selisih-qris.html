Kolom yang dipakai (auto-detect):

Data QRIS —
Drop file Excel / CSV di sini
atau klik untuk pilih file
—
Kolom yang dipakai:
Minera / Orion → B = reference_no (KEY)  |  C = amount
VIP → B = Id Transaction Client (KEY)  |  G = amount
XPay → J = PARTNER ID (KEY)  |  C = RECORD VALUE
P2MIH → D = Order ID (KEY)  |  F = amount
Format auto-detect saat upload — baris 1 di-skip
